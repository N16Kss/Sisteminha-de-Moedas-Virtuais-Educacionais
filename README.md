# Sisteminha-de-Moedas-Virtuais-Educacionais
Sistema de moedas virtuais


## REQUISITOS DO SISTEMA

O sistema deve dar moedas aos professores
Professor deve distribuir moedas
Sistema deve depositar moeda semestralmente
Sistema deve notifcar aluno das moedas
Professores e alunos deevem conseguir depositar moedas
Aluno deve conseguir trocar moedas
Empresas parceiras devem ser possibiltadas de se cadastrar no sistema



Para cadastrar uma vantagem empresas devem adicionar uma descrição e imagem do produto




Alunos podem fazer trocas de moedas enter alunos, mas é necessário aprovação dos professores de mesma turma, não é possível enviar caso não haja professores similares entre os alunos
